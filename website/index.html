The gap

Coding agents know your code.
They do not automatically know your rules.

Company policies often live in PDFs, documents, wikis, and legal text. Development happens somewhere else. RegTrace connects those two worlds inside the coding workflow itself.

01

Policy is disconnected from planning

A feature can be technically valid while its implementation plan already conflicts with internal privacy, security, or governance rules.

02

Code review happens too late

Requirements discovered after implementation create rework. RegTrace introduces policy review before the first code change.

03

Generic advice misses the repository

RegTrace gives Claude the actual local project so policy reasoning is grounded in real files, functions, integrations, and data flows.

Example

A feature can work perfectly
and still conflict with policy.

RegTrace is designed for that gap: functional software whose behavior conflicts with requirements supplied by the organization.

Customer CRM exportPolicy-aware review
Company policy
Customer personal data may only be exported to an external service after explicit user consent.
Implementation
def export_customer(customer): if customer.export_consent: audit.log("consent-observed") crm.send(customer.email)
RegTrace review
Policy issue found · customer_export.py

The consent condition only controls logging. The CRM transfer executes even when explicit consent is absent.

Claude correction
def export_customer(customer): if not customer.export_consent: raise PermissionError(...) crm.send(customer.email)
Fresh review

The reviewed path is now consistent with the supplied policy. RegTrace does not claim universal legal compliance.

Local installation

Clone it. Install it.
Use it inside Claude Desktop.

RegTrace is a local MCP extension. Your repository remains on your machine; Claude receives the repository context through the local extension.

INSTALL

Three steps

1Clone the GitHub repository and install the Python requirements.
2Claude Desktop → Settings → Extensions → Advanced settings → Extension Developer → Install unpacked extension.
3Select the mcp-adapter folder, restart Claude, then attach your policies and give Claude your local repo path.

Python 3.10+ required. If your system does not expose python on PATH, replace the manifest command with your Python executable path.

PowerShell
git clone https://github.com/YOUR_USERNAME/regtrace.git cd regtrace python -m pip install -r .\mcp-adapter\requirements.txt cd .\mcp-adapter python -c "import server; print('REGTRACE SERVER OK')"
